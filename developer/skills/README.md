# OpenFour Developer Skills

Agent-loadable skills for the development workflow, from environment setup through official submission. The agent should drive this with scripts and on-chain calls, not by clicking through the Workbench UI.

| Skill | Purpose |
| --- | --- |
| [`openfour-developer/`](./openfour-developer/SKILL.md) | Automated development of preset modules, presets, and token implementations: fork registration, create/trade verification, AI security audit, and official submit materials |

The human counterpart is [`../workbench/`](../workbench/). This directory is the agent-executable version of the same flow.
